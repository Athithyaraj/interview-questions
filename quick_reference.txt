PROBLEM 1: EMAIL VALIDATION (EXPECTED)
═══════════════════════════════════════════════════════════════════════

KEY REQUIREMENTS:
✓ Trim input string
✓ Normalize case (usually lowercase)
✓ Validate email format
✓ Handle edge cases (null, empty, whitespace)
✓ Return validation result + normalized email

VALIDATION CHECKLIST:
□ Exactly one @ symbol
□ Non-empty local part (before @)
□ Non-empty domain part (after @)
□ Domain contains at least one dot
□ No leading/trailing dots in either part
□ No consecutive dots
□ Local part < 64 chars, domain < 255 chars
□ Extension (after last dot) at least 2 chars

QUICK CODE TEMPLATE:
───────────────────
public (bool IsValid, string Normalized, string Error) ValidateEmail(string input)
{
    if (input == null) return (false, null, "null input");
    
    string trimmed = input.Trim();
    if (string.IsNullOrEmpty(trimmed)) return (false, null, "empty");
    
    string normalized = trimmed.ToLowerInvariant();
    
    // Basic validation
    if (!normalized.Contains("@")) return (false, null, "no @");
    var parts = normalized.Split('@');
    if (parts.Length != 2) return (false, null, "multiple @");
    
    // Validate format...
    if (IsValidFormat(parts[0], parts[1]))
        return (true, normalized, null);
    
    return (false, null, "invalid format");
}

COMMON DATA STRUCTURES IN C#
═══════════════════════════════════════════════════════════════════════

Dictionary<K, V>      O(1) average lookup, key-value pairs
HashSet<T>           O(1) average lookup, unique values only
Stack<T>             LIFO - Push(), Pop(), Peek()
Queue<T>             FIFO - Enqueue(), Dequeue()
List<T>              Dynamic array, O(n) insert, O(1) access
SortedDictionary     Ordered keys, O(log n) operations

QUICK EXAMPLES:
───────────────
// HashMap for lookups
var seen = new Dictionary<int, int>();
if (seen.ContainsKey(key)) { }
seen[key] = value;

// HashSet for uniqueness
var unique = new HashSet<int>();
unique.Add(num);
if (unique.Contains(num)) { }

// Stack for LIFO
var stack = new Stack<char>();
stack.Push(item);
char top = stack.Pop();

// LINQ for functional operations
var result = nums.Where(x => x > 0)
                 .Select(x => x * 2)

UNIT TESTING IN C# (XUNIT STYLE)
═══════════════════════════════════════════════════════════════════════

ATTRIBUTE MEANINGS:
────────────────────
[Fact]           Single test case
[Theory]         Multiple test cases (with parameters)
[InlineData(...)] Pass test data inline
[MemberData(...)] Pass test data from another source

TEST STRUCTURE:
────────────────
[TestMethod]
public void MethodName_Scenario_ExpectedResult()
{
    // Arrange - setup
    var input = "test@example.com";
    
    // Act - execute
    var result = ValidateEmail(input);
    
    // Assert - verify
    Assert.IsTrue(result.IsValid);
    Assert.AreEqual("test@example.com", result.Normalized);
}

ASSERTION HELPERS:
───────────────────
Assert.IsTrue(condition)
Assert.IsFalse(condition)
Assert.AreEqual(expected, actual)
Assert.IsNull(value)
Assert.IsNotNull(value)
Assert.Throws<Exception>(() => code)

C# GOTCHAS TO AVOID
═══════════════════════════════════════════════════════════════════════

STRINGS ARE IMMUTABLE
❌ string result = "";
   foreach (item in items) result += item; // Creates new string each time!
✓ Use StringBuilder instead for loops

NULL CHECKING
❌ if (email != "") { } // Throws if email is null
✓ if (!string.IsNullOrEmpty(email)) { }

DICTIONARY LOOKUPS
❌ var value = dict[key]; // Throws if key doesn't exist
✓ if (dict.TryGetValue(key, out var value)) { }
✓ if (dict.ContainsKey(key)) { var value = dict[key]; }

LINQ ENUMERATION
❌ var list = someLinq.ToList(); // Executes query now
✓ var enum = someLinq; // Lazy evaluation (if IEnumerable)

STRING COMPARISON
❌ if (str1 == str2) { } // Case sensitive
✓ if (str1.Equals(str2, StringComparison.OrdinalIgnoreCase)) { }
✓ string.Equals(str1, str2, StringComparison.CurrentCultureIgnoreCase)
